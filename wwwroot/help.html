启动前准备

  • 安装 .NET 10 SDK。
  • 确认当前目录是完整工程，根目录里有 project.godot。
  • 确认要编辑的 MOD 有 mods/<modId>/mod.json 和 mods/<modId>/data/。
  • 图片、音频等预览资源来自仓库根目录 assets/。

Windows 启动

PowerShell：

cd C:\path\to\jyxr-web-editor
dotnet run --project .\tools\JsonEditor\JsonEditor.csproj

CMD：

cd /d C:\path\to\jyxr-web-editor
dotnet run --project tools\JsonEditor\JsonEditor.csproj

macOS 启动

cd /path/to/jyxr-web-editor
dotnet run --project tools/JsonEditor/JsonEditor.csproj

打开和停止

启动后浏览器打开：

http://localhost:5127

停止服务：回到启动服务的命令行窗口，按 Ctrl+C。

常用命令

dotnet --list-sdks
dotnet run --project tools/JsonEditor/JsonEditor.csproj

基本流程

  1. 右上角选择当前 MOD。
  2. 左侧切换“数据 / 剧情 / 资产”。
  3. 选择 JSON 文件，用“表单”或“JSON”编辑。
  4. 点击“格式化”和“校验”。
  5. 确认无误后点击“保存”。保存会生成备份并再次校验。

Story DSL

新剧情可以在 data/story/ 下创建 .story 文件。打开后使用 DSL 编写，JSON 可查看只读编译预览。

# 书剑入口
南贤：这里是书剑剧情。
主角：要做什么？
- 领取奖励
  random_item [小还丹, 王母蟠桃] 1
  jump 书剑结束

# 书剑结束
南贤：结束。

保存 .story 时会生成同名 .story.json，游戏运行时仍读取 JSON 文件。

常见问题

找不到 project.godot：先 cd 到仓库根目录再启动。

页面没有 MOD：检查 mods/、mod.json 和 data/ 是否存在。

端口被占用：关闭另一个占用 5127 的进程后重新启动。

保存失败：查看右侧校验信息；旧文件备份在 tools/JsonEditor/.backups。
