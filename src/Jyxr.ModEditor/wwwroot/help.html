启动前准备

  • 安装 .NET 10 SDK。
  • 准备一个包含 mods/ 的创作工作区，不要求包含游戏源码或 project.godot。
  • 确认要编辑的 MOD 有 mods/<modId>/mod.json 和 mods/<modId>/data/。
  • 图片、音频等预览资源来自创作工作区根目录 assets/。

Windows 启动

PowerShell：

cd C:\path\to\jyxr-editor
dotnet run --project .\src\Jyxr.ModEditor\Jyxr.ModEditor.csproj -- --workspace C:\path\to\content-workspace

CMD：

cd /d C:\path\to\jyxr-editor
dotnet run --project src\Jyxr.ModEditor\Jyxr.ModEditor.csproj -- --workspace C:\path\to\content-workspace

macOS 启动

cd /path/to/jyxr-editor
dotnet run --project src/Jyxr.ModEditor/Jyxr.ModEditor.csproj -- --workspace /absolute/path/to/content-workspace

打开和停止

启动后浏览器打开：

http://localhost:5127

停止服务：回到启动服务的命令行窗口，按 Ctrl+C。

常用命令

dotnet --list-sdks
dotnet run --project src/Jyxr.ModEditor/Jyxr.ModEditor.csproj -- --workspace /absolute/path/to/workspace
dotnet build Jyxr.ModEditor.slnx
node --check src/Jyxr.ModEditor/wwwroot/app.js
cd src/Jyxr.ModEditor && npm test

基本流程

  1. 右上角选择当前 MOD。
  2. 左侧切换“数据 / 剧情 / 资产”。
  3. 在专用工作区进行结构化创作；未覆盖的内容在“高级数据”中编辑完整 JSON。
  4. 点击“格式化”和“校验”。
  5. 确认无误后点击“保存”。保存会生成备份并再次校验。

Story DSL

新剧情可以在 data/story/ 下创建 .story 文件。打开后使用 DSL 编写，JSON 可查看只读编译预览。

文本编辑区使用 Monaco，支持行号、缩略代码地图、DSL/JSON 高亮和错误定位。顶部“跳转剧情段”下拉会按 # 段名 或 JSON 的 name 快速定位。

# 书剑入口
南贤：这里是书剑剧情。
主角：要做什么？
- 领取奖励
  random_item [小还丹, 王母蟠桃] 1
  log 书剑剧情已领取奖励
  jump 书剑结束

# 书剑结束
南贤：结束。

保存 .story 时会生成同名 .story.json，游戏运行时仍读取 JSON 文件。右侧会检查 jump、战斗、地图、商店和物品引用是否存在。

DSL 写法速查

段落：顶格写 # 段名。

# 初遇南贤

对白：写成 说话人：文本，中英文冒号都可以。

南贤：少侠，且慢。
主角: 我听着。

普通命令：命令名后接参数；列表参数使用方括号。

item 小还丹 1
get_money 500
random_item [小还丹, 王母蟠桃] 1
jump 下一段剧情

选择：提示对白后跟同级 - 选项，选项内容缩进 2 个空格。

南贤：你要去哪？
- 去洛阳
  map 洛阳
- 继续聊
  jump 继续聊天

条件：支持 if / elif / else。

if money >= 500
  cost_money 500
  南贤：银两收下了。
else
  南贤：条件还不够。

战斗：使用 battle 战斗id，结果只允许 win、lose、timeout。

battle 新手战斗
- win
  get_money 100
  jump 战斗胜利
- lose
  jump 战斗失败

缩进必须使用 2 个空格，不要使用 Tab。jump 后面的同级语句不可达，会作为错误提示。

常用剧情命令

  • 物品：item、cost_item、random_item
  • 银两 / 元宝：get_money、cost_money、yuanbao
  • 时间：cost_day、set_time_key、clear_time_key
  • 状态：set_flag、clear_flag、daode、haogan、rank、menpai
  • 角色：join、follow、leave、leave_follow、leave_all
  • 成长 / 技能：grant_exp、levelup、learn、remove、maxlevel
  • 流程：map、shop、battle、jump
  • 表现：music、effect、background、suggest、toast、shake、head、animation

编辑器会静态检查 jump、battle、map、shop 和物品类引用；其他命令以运行时和内容校验为准。

常见问题

缺少创作工作区：使用 --workspace 传入包含 mods/ 的绝对路径。

页面没有 MOD：检查 mods/、mod.json 和 data/ 是否存在。

端口被占用：关闭另一个占用 5127 的进程后重新启动。

保存失败：查看右侧校验信息；旧文件备份在当前 MOD 的 .jyxr-editor/backups。
